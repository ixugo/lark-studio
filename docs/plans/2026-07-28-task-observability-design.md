# 任务可观测性与交互完善设计

## 目标

本次改动让任务从创建到完成始终具备可信、单调、可恢复的进度和日志，同时完善 Whisper 安装、模型管理、设置兼容与词库交互。

## 数据设计

`Task.Progress` 只表示总进度，取值始终为 0 到 100，并且运行期间只能前进。`Step.Progress` 表示当前步骤进度，增加模型名称、状态说明和耗时字段。流水线按模式使用固定步骤权重，把步骤进度换算成总进度。

新增 `TaskLog` 记录任务日志，字段包含任务 ID、级别、步骤、消息和创建时间。每个任务最多保留 1000 行；插入新行后在同一事务中删除最旧的超额记录。历史日志按时间正序查询，实时日志通过 WebSocket 携带同一个任务 ID 推送。

## Whisper 与流水线

macOS 构建产物优先使用应用内的 `whisper-cli`，系统 PATH 作为回退。引擎页面显示真实检测结果，不再硬编码“可用”。模型管理下载 GGML 模型，并在 Apple 芯片上同步下载和校验 CoreML 编码器。

Whisper 使用 stdout/stderr 管道实时读取输出，解析百分比并转为中文日志。TTS 每完成一句更新数量和百分比。FFmpeg 烧录持续解析 stderr，同时将节流后的原始进度行写入任务日志。成功、失败、重试、耗时和降级均进入同一任务日志链。

## UI

任务列表只显示中文状态。标题下显示模式和创建时间；右侧显示模型名称、步骤进度或完成耗时。总进度条使用总进度字段，步骤链使用步骤进度字段，二者互不覆盖。

运行中的步骤采用呼吸光晕、流动连线和进度平滑插值。动画从当前显示值继续，不允许回跳；系统启用“减少动态效果”时只保留颜色和透明度反馈。

词库列表移除排序按钮，增加真实开关和右键删除。hover 与选中态共用一个背景状态。搜索输入停顿 300 毫秒后自动查询。新增词条按钮复用应用按钮组件。

## 验证

每个提交必须通过对应单元测试和静态检查。最终执行：

- `go test ./...`
- `go build ./...`
- `flutter test`
- `flutter analyze`
- `flutter build macos --debug`
- 实机点击启动台、任务、引擎、词库、设置
- 使用短音频验证 Whisper 百分比、日志顺序、总进度单调和历史日志恢复
